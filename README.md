# English Proficiency Exam Pro Showcase

This is a responsive, single-page showcase for the "English Proficiency Exam Pro" organization. It features multiple, switchable layouts to display course information in different styles.

## Features

- **Four Unique Views**: Classic, Modern, Interactive, and Results-focused layouts.
- **Responsive Design**: Looks great on all devices, from mobile phones to desktops.
- **Interactive Elements**: Includes hover effects, accordions, and smooth transitions.
- **Built with Modern Tech**: Created with React, TypeScript, and styled with Tailwind CSS.

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need to have [Node.js](https://nodejs.org/) (version 18 or later) and npm installed on your computer.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url>
    cd <repository-folder>
    ```

2.  **Install NPM packages:**
    ```bash
    npm install
    ```

### Running the Development Server

To view the application in your browser and see changes live as you edit the code, run the following command:

```bash
npm run dev
```

This will start the Vite development server, and you can open your browser to `http://localhost:5173` (or the URL provided in your terminal) to see the app.

## Available Scripts

-   `npm run dev`: Runs the app in development mode.
-   `npm run build`: Builds the app for production to the `dist` folder.
-   `npm run preview`: Serves the production build locally.
